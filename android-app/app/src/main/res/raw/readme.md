# Custom Alarm Audio Directory

Place your audio file named `heavy_alarm.mp3` (or `.ogg`, `.wav`) directly in this directory:
`android-app/app/src/main/res/raw/heavy_alarm.mp3`

> **Note**: If no custom `heavy_alarm.mp3` file is added, `AlarmRingerService` automatically falls back to your device's default system alarm and ringtone audio streams (`RingtoneManager.TYPE_ALARM`).
